# PWA Icons

Generate the icon files using a tool like:

- https://realfavicongenerator.net
- https://www.pwabuilder.com
- https://favicon.io

Upload your logo (minimum 512x512px PNG with transparent background) and generate icons for all sizes listed in `/manifest.json`.

Required sizes: 48, 72, 96, 128, 144, 152, 192, 384, 512

Place the generated files in this directory as `icon-{size}.png` (e.g., `icon-192.png`).
